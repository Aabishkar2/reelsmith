# reflective · reference

`index.html` is the approved reference video for this pack (`devotion-tts`, 9 scenes, TTS voice at 1.15× under a 6 dB music bed). `styles/reflective/STYLE.md` names its scenes (`Scene1` … `Scene9`) in the layouts and transitions tables.

It is shipped as **code to read**, not a runnable page: its photos (Unsplash / Wikimedia, credited per file in the original `images/CREDITS.md`) and its `scenes.json` are not in the framework. The style kit block at the top of its script is the same code as `styles/reflective/kit.jsx`; new videos include the kit instead of copying it.
